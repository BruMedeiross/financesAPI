## App Features
* Show list of events
* A simple plain text search

- Retrofit
- ARCH: MVVM
- DI: Koin
- Arch Components: ViewModels, Coroutines, DataBinding, LiveData
- Material Design: RecyclerView, CardView.
- SearchView
- Shimmer
- *TEST: Unit (JUnit) and automated (Espresso + Roboeletric)*
